- 2026-10-24 17:50Z [FAILED] The duplicate rule was too loose in two ways, caught by reading the first Valhalla list. (1) For GitHub links, enrich stores the repo's `html_url` as `final_url`, so two different files of one awesome-list repo (and a repo's wiki page vs the repo) were "duplicates". (2) Five Fleek pages (blog posts, docs) all redirect to the new `fleek.sh` home page and were called duplicates of each other. New rule **`gone`**: a deep link that now redirects to its site's home page ("the page is gone: it now redirects to fleek.sh's home page").
