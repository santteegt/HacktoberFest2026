RC Pit Companion

A setup coach and setup vault for a 1/10 touring car that runs on your laptop. This page gets it running, then shows how to use it at the pit table.

Install

Pick the model first. The small one is the safe choice for an older Intel laptop. The bigger one gives nicer wording if the laptop is fast.


      
The first line downloads the project. The ollama pull line downloads the model, which is the slow part. npm ci installs packages and builds the offline notes index.

      

      
This edits the .env file so the app asks Ollama for the model you pulled.

Start it

      
npm start

      
Wait for the line that says the server is running, then open http://localhost:8787 in Chrome. Leave the terminal window open while you use the app. Press Ctrl+C in it to stop.

Things worth knowing

        
    
          
  • It changes one thing at a time on purpose. If you change two, you cannot tell which one helped.
    • 
          
  • Every answer lists the notes it came from. Tap a citation to read the source.
    • 
          
  • Questions outside the notes get a refusal. That is by design.
    • 
          
  • Chips and typed keywords work even if Ollama is off. The model only improves how it understands and words things.
    • 
          
  • Most adjustment rows are marked draft. Treat those as a starting point, not as gospel.
    •

Voice

      
Push-to-talk works in desktop Chrome when the browser can recognise speech on the device. It has not been checked on this laptop yet, so test it before relying on it.

      

        
    
          
  1. Open Settings, then the voice section.
    2. 
          
  2. If it says the speech pack is missing, press Install speech pack. That needs internet once.
    3. 
          
  3. Press Test voice input and say a sentence. If nothing happens, use chips or type. Nothing else in the app depends on voice.
    4.

Try it with Wi-Fi off

      
Once the model is pulled and npm start is running, turn Wi-Fi off and do one coach turn. It should still answer. Then send back what you saw.

      
ollama run gemma4:e2b-it-qat --verbose

      
Ask it one short thing. When it finishes it prints "prompt eval rate" and "eval rate" in tokens per second. Those two numbers are the useful part.

      
Please send:
- macOS version
- prompt eval rate and eval rate (tokens/s) from the command above
- seconds from tapping a chip to seeing text, and the same for a typed sentence
- did the mic work with Wi-Fi on? with Wi-Fi off?
- anything confusing or slow

If something goes wrong

      

        

          The app says "Ollama not reachable"
          
Open the Ollama app so its menu bar icon appears. Reload the page. Chips and typed keywords still work without it.

        

        

          The app says the model "is not pulled"
          
Run the pull command from step 2 for the model you chose. Check the name in .env matches it exactly.

          
ollama list

        

        

          npm start stops with a message about kb.json
          
The offline notes index is missing. Rebuild it, then start again.

          
npm run kb:build

        

        

          The port is already in use
          
Another copy is still running. Close its terminal window, or set a different port in .env (PORT=8790) and open that address instead.

        

        

          The answer is slow
          
On a CPU-only laptop the first answer after starting is the slowest because the model has to load. Use the small E2B model, close other heavy apps, and use chips, which skip one of the two model steps.

        

        

          It misread what I said
          
Tap the right chip instead, and tell the author the exact words you used. Real phrasings are what the app learns from most.
