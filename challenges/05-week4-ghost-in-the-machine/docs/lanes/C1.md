# Lane C1: comic template and renderer

Model: Claude Opus (closed model) designed the template once. No model writes anything at render time; `ghosts/render.py` only fills placeholders and escapes values.

## What was built (2026-10-29, M4 Max, Python 3.12 via uv)

- `template/ghost.html` master page; `template/panels.html` named fragments (`<!--@ name -->`: title, cover, record, chapter, timeline, closing, smallprint), all `string.Template`; `template/ghost.css` (~20 KB), `template/ghost.js` (~2 KB, reveal-on-scroll + copy button, no network).
- `template/characters/*.svg`, hand-authored, inlined at render time with `$uid` (unique `<title>` ids) and `$tag` (address prefix):
  - `storyteller.svg`: a calavera narrator in a deep-purple hood with a marigold crown, sugar-skull eyes, pink cheek swirls, holding a candle whose flame flickers.
  - `ghost.svg`: a floating sheet ghost carrying a yellow hex tag (`0x2af4…`); four faces in one file (friendly smile, lingering sad eyes and tear, bad red eyes and jagged teeth with a pink glow, banished X eyes and faded), picked by CSS from `<body data-kind>`.
  - `contract.svg`: the contract while alive, a happy marigold/purple block with its tag; it flies in the birth and life chapters, the ghost from the silence chapter on. That swap is the visual "when it became a ghost".
  - `gravestone.svg` (banished only), `papel-picado.svg` (repeating pattern banner).
- `ghosts/render.py`: `render(address, data_dir=None, out_dir=None) -> Path` and `render_all(data_dir=None, out_dir=None) -> list[Path]`. Reads facts, verdict, story, wounds, shots/index.json; degrades to a facts-only page ("The storyteller has not spoken yet" balloon, "Unclassified" badge) when verdict/story/wounds are missing; synthesizes a haunting panel for a bad ghost with wounds but no story.
- Panels: title (title, tagline, kind badge, age, born/last-seen chips, storyteller, flying ghost, falling marigold petals, moon), optional cover (shots role `cover`, copied to `cover.png`), ofrenda card (address + copy button, born date and block, age, deployer short, last seen date and method, lifetime calls, token transfers, balance, code on chain, verified source, compiler, historian story yes/no, kind badge + verdict reasons), one panel per chapter with balloons and `facts_cited`, haunting (scary balloons, wound list with confirmed/suspected pills, incident line, guilty code with real line numbers and file name), ghost buster (buster balloons, beam, fix labelled "Solidity 0.8.38, compiled: yes/no", compiler output if it failed), timeline (born, site first/last live capture, incident, last call; proportional track plus an accessible ordered list; kind-specific "ghost moment" sentence), closing tally (sentences/grounded/repaired/dropped, dropped sentences struck through), small print (model line, honesty line about the template, source links).
- Fixtures: `tests/fixtures/c1/ghosts/<address>/` for KingOfTheEtherThrone (friendly), Rubixi (bad, SWC-118 constructor-name wound, fix not compiled), StandardBounties (lingering). Facts are copies of the real facts.json; verdict/story/wounds are hand-written by this lane to match the schemas in `docs/LANES.md`. Their `model.id` starts with `fixture`, so the page says "hand-written test fixture, not model output".
- Tests: `tests/test_c1_render.py`, 11 tests, no network: key strings per kind, sizes, no http(s) outside the small print, no external script/link, guilty-code line numbers, fix label, struck dropped text, facts-only degrade, control-character name fallback, HTML escaping (title, paragraphs, code, incident), `javascript:` URLs dropped, cover copy with the real Lane D `shots/index.json` format, `render_all`.

## Failures and fixes

- Headless Chrome with `--virtual-time-budget` never fired the IntersectionObserver, so every panel stayed transparent. Added a fallback in `ghost.js`: if the observer reports nothing in 1.5 s, show all panels. This also protects Lane D's or any crawler's screenshots.
- Lane D's `shots/index.json` uses `file: "shots/<ts>.png"`, a full Wayback URL in `url` and an extra `site` key; the first version wrapped the URL in a second Wayback prefix. Fixed and covered by a test.
- `facts.name` for TheDAO is `"\u0001"`; the renderer falls back to the first printable name of eh.name, blockscout.name, source.name, token name, then the short address.
- Wayback `first_ok` dates before Ethereum genesis (TheDAO's Wikipedia/CoinDesk "sites" from 2003-2004) are dropped from the timeline and sources.

## Honest limits

- The three fixture stories are mine, written to exercise the template; they are not Gemma output and their verifier numbers are invented for layout. The pages in `web/ghosts/` for those three addresses are fixture pages until the real story.json lands and someone runs `ghosts render-all`.
- The page has one fixed night theme (no light mode); explicit body background, so it reads the same everywhere.
- Fonts are system fonts; the balloon face falls back from Chalkboard SE / Comic Sans MS to the system UI font on Linux/Android.
- The timeline track is proportional, so events in the same month overlap on the bar; the list under it carries the real dates.
- The ghost "moment" for a lingering ghost uses `verdict.activity.last_12m_txs`; the fixture value (7) is EH's 2025 yearly count, not a last-12-months count.

## Reveal fix (2026-10-29)

- Bug (coordinator): at 1100×900 in headless Chromium, only panels the IntersectionObserver reported got `seen`. The first fallback ran only when the observer reported nothing at all; this time it had reported once, so the panels further down stayed at opacity 0.
- Fix: `ghost.js` now calls `revealAll()` immediately under reduced motion or when there is no observer, always after 1.5 s, and on `beforeprint`. `ghost.html` adds a `<noscript>` style that sets `.reveal` and balloons to opacity 1 with no transform.
- Check: Unitroller fixture in headless Chrome at 1100×900, `--virtual-time-budget=3500 --dump-dom`: 7 of 7 `.reveal` panels have `seen`. Suite: 223 passed.
- Trade-off: panels below the fold no longer fade in on scroll after the first 1.5 s; they are already visible.
