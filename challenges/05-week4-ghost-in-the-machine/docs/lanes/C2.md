# Lane C2: gallery site and Vercel (2026-10-28, M4 Max, Claude Sonnet 5.5)

## Built
- `ghosts/gallery.py`: `build()` scans `data/ghosts/*/` (facts, verdict, story when present) and `web/ghosts/*/index.html`; writes `web/ghosts/index.json` (LANES.md schema, only ghosts with a rendered page, newest `story.generated_at` first, fallback the page's mtime) and `web/sitemap.txt`. Deterministic, so a second run is byte-identical. Fallbacks: name from story, facts, EH, then short address; kind from verdict, then story, else `unknown`; tagline from story, else the first 200 chars of EH `short_description`; `cover` only when `cover.png` sits next to the page. Paths are read from `config` at call time (tests monkeypatch `config.ROOT` and `config.GHOSTS_DIR`).
- `web/index.html`, `web/assets/site.css`, `web/assets/site.js`: framework-free, no CDN, system fonts, phone-first; cards with name, kind badge, age, born, last seen, balance, historian yes/no, tagline; filters by kind and age, search, sort (newest, oldest birth, silent longest, balance); model-written text goes in through `textContent` only. Checked in the in-app browser at 1024 and 375 px wide (no horizontal scroll) with four fake pages; kind filter and search verified.
- `web/vercel.json` (no build, clean URLs, cache: `ghosts/index.json` 60 s, `ghosts/*` 300 s + SWR, `assets` 1 h + SWR; the index.json rule must come last or the broader rule wins), `web/.vercelignore`.
- `scripts/deploy.sh`: `ghosts gallery build` (falls back to `python -m ghosts.gallery build` until the CLI wiring exists), then `vercel deploy --prod --yes` from `web/`, `--token` only when `VERCEL_TOKEN` is set. Vercel CLI 62.2.0 prints JSON on stdout when not on a TTY, so the script reads `deployment.url` from it (plain last line for older CLIs). Exits non-zero on any failure.
- `tests/test_c2_gallery.py` (4 tests, offline, fixtures in `tests/fixtures/c2/`): schema, page-less ghost excluded, order, fallbacks, sitemap, idempotence, empty case.

## Vercel

It also tried to connect the GitHub repo (failed, harmless: we deploy by CLI) and wrote `web/.env.local` (an OIDC token) and `web/.gitignore`; both deleted, `.env*` is now in `.vercelignore`. `.vercel/` is gitignored at the root.
- `vercel domains add eth-ghosts.decentraminds.tech eth-ghosts` worked with no prompt. The zone already had a wildcard ALIAS, so no DNS record was needed.
