## Definition

Every Hacktoberfest 2026 DEV Challenge uses the same prompt: build something with open-source AI at its core. Only the weekly theme changes.

## Key Points

- "Open-source AI" can mean running an open-weight model, building on an open-source agent harness or framework, running inference locally, or all three. The open pieces must be what makes the project work.
- The post must say **why open matters**: offline on a laptop, data kept off servers you don't control, fine-tuning or swapping models or changing agent behavior, cost nothing to run, or where it beat a closed approach.
- Each submission must be a **new project built during the challenge window**, and each challenge is a fresh start.
- Themes are revealed each Monday (Oct 5, 12, 19, 26). The weekend theme was [Build for a Friend](weekend-challenge-build-for-a-friend.md).
- Judging puts the most weight on Writing Quality, then relevance, creativity, technical execution, and optional partner-tech use.
- Saving an agent session with DevRelay and embedding it in the post is encouraged (optional); see [DevRelay](devrelay.md).
