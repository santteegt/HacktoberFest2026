## Definition

Gradient AI Platform offers serverless inference with an OpenAI-compatible API, agents with knowledge bases for RAG, and dedicated GPU inference for open and commercial models.

## Key Points

- Docs [docs]: multi-agent routing and guardrails; the Agent Development Kit is deprecated as of Oct 2026; a prepay Inference and Agents balance ($5 to $500, no expiry).
- Report: catalog includes gemma-4-31B-it, gpt-oss, Llama, Qwen and Mistral; GPU Droplets; about $5 new-account credit for 90 days; Hacktoberfest promo unverified.
- Fits: hosting an open model for a user whose machine is too weak; a hosted fallback next to a local-first design (costs the offline story).
