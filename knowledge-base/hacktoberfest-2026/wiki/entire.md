## Definition

Entire records prompts, transcripts and file changes as checkpoints tied to commits so any change can be traced back to the session behind it.

## Key Points

- `entire enable --yes --agent <name>` inside a repo; commands include blame/why, session resume, review/recap and search; mirrors sync to GitHub in US, EU, India and Australia regions [docs].
- Agents named in docs: Codex, Claude Code, Antigravity; the report adds OpenCode, Gemini and Copilot CLI; CLI is MIT [report]. Secret redaction not covered on the page fetched: scrub transcripts yourself.
- Dropped in the weekend build for workload; DevRelay's agent-session tool was used instead.
- Fits: a process angle in the post, only if shown to matter.
