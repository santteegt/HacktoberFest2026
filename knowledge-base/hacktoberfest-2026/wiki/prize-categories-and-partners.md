## Definition

Each Hacktoberfest DEV Challenge can award prizes for the best meaningful use of a partner's technology. Entries qualify automatically for every category they fit, but a single participant can win only once per challenge.

## Key Points

- **Weekend featured ($200):** Render, TabPFN (Prior Labs), Tinker (Thinking Machines), Arduino, DigitalOcean, Gemma.
- **Weekend categories ($100):** Backboard, ElevenLabs, Entire, GitHub Copilot, Mastra, MongoDB Atlas, SerpApi, Sentry Agent Tracing, Temporal, Tiger Data.
- Category winners are drawn from a smaller pool, which raises the odds of winning.
- Some partners offer free credits and promo codes (Tinker, Render, Backboard, and others), claimable at https://hacktoberfest.com/my.
- Other Hacktoberfest sponsors named on the site: Snowflake, Gauge, Solana, IBM, Paper Compute, Google Cloud, Qualcomm, TLDR, MongoDB, Tiger Data, GitHub, Sentry, ElevenLabs.
- Sponsor agent skills exist for MLH events (`devrelay-sponsor-skills`); ask before installing.
- **Status (2026-10-05):** every weekend partner now has a feature page, summarised in the [Partner tools catalog](partner-tools-catalog.md). Only [Gemma](gemma.md) and [Mastra](mastra.md) were really used in the weekend build; the rest are documented from docs and a partner report only, with verification tags. Re-fetch the challenge details for weeks 1 to 4, which may list other partners.
