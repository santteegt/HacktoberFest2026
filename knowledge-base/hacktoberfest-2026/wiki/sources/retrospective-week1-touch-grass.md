## Notable Points

- A hidden web page gets no GPS fixes, found only by four short real walks; it reshaped the app (screen stays on behind a black cover).
- The 12B model told the author a wrong answer was right and called a quiz ready when it was not; the fix was to send grades and "ready" messages from code.
- DEV kept showing the old diagram until the image URL changed; every API update replaces the whole body, so the live draft has to be fetched before each update.
- The final post was about 2,600 words and the author cut the test table, the OKF subsection and the "what the tests changed" list in the last pass.
