## Summary

DevRelay's general guide to Global Hack Week (verified 2026-09-30). GHW is a free, online, week-long MLH event held monthly, with daily livestreamed workshops, challenges that earn experience points, Discord mini-events, and swag for fully checking in. The guide deliberately omits any single week's dates and challenge list, which must be fetched live.

## Key Concepts

- [Global Hack Week](../global-hack-week.md)
- [Sticker milestones](../sticker-milestones.md)

## Notable Points

- MLH does not publish per-challenge point values.
- Basic swag needs full check-in (Discord, address, all registration challenges); bonus stickers need 5 live sessions.
- The `/schedule` page can lag behind the real event, so check `events.mlh.com`.
