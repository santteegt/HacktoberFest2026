## Definition

In VS Code, Copilot chat can use models from other providers, local runtimes and custom endpoints, without a Copilot plan for BYOK.

## Key Points

- BYOK providers: the official Ollama extension, a Custom Endpoint speaking Chat Completions, Responses or the Anthropic Messages API [docs].
- Agent mode, custom instructions, prompt files and MCP servers work with local models that support tool calling; semantic search, inline suggestions and embedding features need the Copilot service [docs].
- Fits: Copilot as the build tool around an open model (say how it mattered); weak as a product feature.
