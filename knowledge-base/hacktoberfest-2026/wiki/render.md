## Definition

Render deploys apps from Git or Docker and offers managed Postgres and a Redis-compatible Key Value store.

## Key Points

- Free tier [docs]: 750 instance hours per month per workspace; web services spin down after 15 minutes idle and take about a minute to restart; free Postgres expires after 30 days (1 GB); Key Value is in-memory only; no persistent disk or SSH on free web services; SMTP ports blocked.
- No GPU offering found [report]; promo available.
- Fits: a public demo link or webhook for an open-model project; weak for a privacy-first story.
